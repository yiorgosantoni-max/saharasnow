# Earnings visibility update

- Public seller profile pages do not expose total earnings.
- Authenticated buyer/seller account modal now has a private **Earnings** tab.
- Sellers can see total released earnings, pending earnings, and available balance there.
- Buyers see the Earnings tab too, with an explanation that seller earnings are only available in Seller mode.
- Admin dashboard has a dedicated **Earnings** tab showing each user, email, mode, total released earnings, pending earnings, and available balance, sorted by total released earnings.
- Existing notification clearing and suspended-login-code protections remain included.
